# Nausheen Pet Care Center — FSD-2 Website

## Open the website
Double-click `index.html`. No server or installation is required.

## Pages
- Home
- About Us
- Services
- Appointment
- Gallery
- Contact

## Features
- Light pink + white responsive design
- Mobile navigation
- Reusable aesthetic layout
- Appointment form with browser localStorage demo
- Contact form confirmation
- User-provided clinic images included locally
- No external libraries required

## Note
The phone number, email and Hyderabad location are demo details for the college project and can be replaced in the HTML files.
